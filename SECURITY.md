# Security policy

Please do not report security problems in public issues.

Use [private vulnerability reporting](https://github.com/HttpRafa/pelican-provisioner/security/advisories/new). If that page is not available, open an issue that asks for a private contact and leave out the details.

Include the plugin and panel versions, what an attacker needs (for example a quota or an admin role), and how to reproduce the problem.

Fixes go into the latest release. Problems in the panel itself belong with [Pelican](https://github.com/pelican-dev/panel).
